# Periodogram-Based Time Series Analysis

## Overview
This project explores time series analysis using periodograms to identify dominant periodic patterns in monthly data.

## Objectives
- Analyze periodic patterns in time series data.
- Apply STL decomposition and detrending.
- Compare periodogram results for raw and detrended data.
- Investigate seasonal components with different periods and noise levels.

## Tools & Technologies
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Statsmodels
- SciPy

## Project Type
University Coursework / Assignment

## How to Run
1. Download or clone this repository.
2. Open `Periodogram_Completed.ipynb` in Jupyter Notebook.
3. Run all cells to reproduce the analysis and visualizations.

## Note
This project was completed as part of academic coursework. The notebook demonstrates practical applications of time series analysis and frequency-domain methods.
